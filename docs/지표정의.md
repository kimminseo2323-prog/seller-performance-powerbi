# 지표 정의 (KPI Dictionary)

모든 지표는 `fact_order_seller`(주문×판매자 1행) 기준이며, 슬라이서(기간·지역·카테고리)에 따라 다시 계산됩니다.

| 지표 | DAX | 정의 | 왜 보나 |
|---|---|---|---|
| 매출 | `SUM(gmv)` | 상품 가격 합계(배송비 제외), 브라질 헤알(R$) | 판매 규모 |
| 주문 건수 | `COUNTROWS(fact)` | 주문×판매자 건수 (한 주문에 판매자가 2곳이면 2건) | 판매자 관점의 처리량 |
| 활성 판매자 수 | `DISTINCTCOUNT(seller_id)` | 기간 내 주문이 1건 이상인 판매자 | 판매자 풀 규모 |
| 신규 판매자 수 | `TREATAS(월, cohort_month)` | 첫 주문월이 해당 월인 판매자 | 유입 추세(코호트) |
| 객단가 | `DIVIDE(매출, 주문 건수)` | 주문 1건당 매출 | 상품 믹스 변화 |
| 매출 전월 대비 | `DATEADD(-1, MONTH)` | (이번 달 − 지난달) / 지난달 | 성장률 |
| 배송 지연율 | `AVERAGE(is_late_delivery)` | 고객 수령일 > 약속일인 비율 (배송 완료 건만) | 고객 경험 |
| 출고 지연율 | `AVERAGE(is_late_handoff)` | 택배 인계 > 판매자 출고 기한(shipping_limit)인 비율 | **판매자 책임** 운영 지표 |
| 평균 리드타임(일) | `AVERAGE(lead_time_days)` | 주문 → 고객 수령 | 배송 속도 |
| 평균 출고 소요(일) | `AVERAGE(handoff_days)` | 결제 승인 → 택배 인계 | 판매자 처리 속도 |
| 취소율 | `AVERAGE(is_canceled)` | 상태가 canceled·unavailable인 비율 | 재고·운영 문제 |
| 평균 평점 | `AVERAGE(review_score)` | 1~5점 | 만족도 |
| 저평점 비율 | `AVERAGE(is_low_review)` | 1~2점 비율 | 불만 신호(문의 대용) |
| 불만 건수 | `NOT ISBLANK(complaint_type)` | 저평점 리뷰 건수 | 불만 규모 |
| 1천 주문당 불만 | `불만 건수 / 주문 건수 × 1000` | 규모가 다른 집단 비교용 정규화 | 카테고리·월 비교 |
| 지연/정시 배송 저평점 비율 | `CALCULATE(..., delivery_status = ...)` | 배송 상태별 저평점 비율 | 지연이 만족도에 주는 영향 |

## 판매자 등급 (seller_scorecard, 최근 3개월·주문 10건 이상)
| 등급 | 조건 (위에서부터 먼저 해당) |
|---|---|
| D 집중 관리 | 출고 지연율 ≥ 20% 또는 저평점 비율 ≥ 25% |
| C 주의 | 출고 지연율 ≥ 10% 또는 저평점 비율 ≥ 15% |
| A 우수 | 출고 지연율 ≤ 5% 이고 평균 평점 ≥ 4.3 |
| B 보통 | 그 외 |

기준값은 전체 평균(출고 지연율 약 9%, 저평점 약 15%)을 보고 정한 운영 규칙이며, 실제 운영에서는 조직 목표에 맞춰 조정합니다.

## 불만 유형 (저평점 리뷰 코멘트, 포르투갈어 키워드 규칙)
오배송·구성 누락 → 미수령 → 배송 지연 → 품질·파손 → 취소·환불 요청 → 판매자 응대 불만 → 기타 순으로 먼저 맞는 1개.
코멘트가 없으면 '코멘트 없음'. 규칙은 `sql/02_mart.sql`의 `complaint_type` 매크로.
